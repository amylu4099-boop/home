## Step 2：四个版本正文

## 版本 A：核心摘要

```
嘴比脑子快的人，早晚会栽在自己话上。这不是吓唬人，是一个踩过坑的中年人用六句话总结的教训：言多必失、别随便指点别人、别随便批判别人、藏住底牌、远离消耗你的人、看破不说破。每一句背后都是一个真实的翻车现场——有人在酒桌上抱怨领导，第二天话就传到了领导耳朵里；有人爱替人出主意，最后朋友反目；有人爱炫耀，结果招来一堆借钱的和背后酸的。这六句话合在一起讲的不是"会说话"，是"管住嘴"。记住：说话是本能，闭嘴才是修行。开口之前先停三秒，比说完再后悔划算得多。这辈子能不能少栽跟头，往往不在你做过什么，而在你说过什么。
```

## 版本 B：结构化文章

```
## 嘴快的人，不是输在嘴，是输在没想明白这六件事

你有没有这种朋友——哪儿都有他，什么话都敢接，饭局上喝两杯就开始指点江山。你当时觉得他真能聊，事后才发现，他说的那些话，过几天准给他惹点事。

这不是段子，是规律。嘴比脑子快的人，早晚栽在自己话上。

今天这篇，不讲大道理，就讲六句话，外加九条"不争"。都是一个中年人一个坑一个坑踩出来的。

### 一、说话的三层底线

第一层：**言多必失**。

见人少说话，见事少开口。不是不让你说话，是让你把话挑到该说的地方说。你以为你在聊天，其实在送把柄；你以为你在交心，其实在亮底牌。我见过一个人在酒局上喝多了，跟不太熟的人抱怨领导，第二天这话就传到了领导耳朵里。他还在那纳闷：谁出卖了我？其实没人出卖他，是他自己把话送出去的。

记住：慎言不是胆小，是清醒。水太深、风太大，没有实力就少说话。

第二层：**别随便指点别人**。

你越热心给别人建议，别人越不领情；你越替别人操心，别人越觉得你多管闲事。因为你给建议的时候，本质是在告诉对方"我比你懂得多"。你替人做决定的时候，本质是在替他背因果。

你自己的因果还没搞明白，非要去沾别人的。认知不同，少言为贵；三观不合，浪费口舌。人各有各的渡口，各有各的舟，不打扰就是最好的尊重。

第三层：**别随便批判别人**。

未经他人苦，莫劝他人善。你若经他苦，未必有他善。每个人能扛的重量不一样，你站在岸边看别人在水里挣扎，觉得他为什么不游快一点，等你下去了才知道水有多深。

别用你的想象去评价别人的人生。你没走过他的路，别说他的选择不对。每个人心里都有一团火，路过的人只看到了烟。

### 二、处世的三层智慧

第四层：**学会藏住底牌**。

一个人真正厉害的地方，不是什么都敢说，是什么都能藏。把想说的话咽回去，把想证明的心收起来。你不需要向任何人证明什么，你的价值不在别人的评价里。

我认识一个人，特别爱炫耀——赚了多少钱、认识什么人、去了什么地方，恨不得让全世界知道。结果找他借钱的人越来越多，背后酸他的人越来越多。你亮出来的每一分，都是在给别人递刀：嫉妒你的恨你，不如你的酸你，比你强的懒得理你。图什么呢？藏住底牌不是不真诚，是给自己留余地。

第五层：**远离消耗你的人**。

只要察觉一个人心性不正，一个字都别跟他说。佛法不度无缘之人，有些人你救不了，也不必救。你跟他多说一句，他就拉低你一分；多纠缠一次，他就消耗你一分。

你身边有没有那种人？见面就倒苦水，开口就怨天怨地怨空气。你听他说完，自己心情也跟着沉下去；你给他出主意他不听，你劝他两句他怼你十句。这种人不是来找答案的，是来拉你下水的。趁早远离不是冷漠，是自保。

第六层：**看破不说破**。

这是最顶级的修养。你心里清楚就行，没必要说穿。看清了看懂了，心里有数就行。笑而不语是大度，痛而不言是历练。时过境迁，曾经看不惯的人和事，也不过是淡然一笑。

一个人的成熟，不是看破，而是看淡。

### 三、最后的九条"不争"

人到中年，该明白这九条不争了：

跟父母不争口舌，跟伴侣不争对错，跟贵人不争名利，跟小人不争道理，跟朋友不争面子，跟亲戚不争穷富，跟老人不争声张，跟领导不争高低，跟自己不争得失。

这九条要是能记在心里，这辈子至少少得罪一半的人。

最后送你三句话：**说话是本能，闭嘴是修行；开口之前先停三秒，有些话烂在肚子里比说出来更值钱。**

书名叫《好好说话》，我把它放在主页橱窗了。讲的不是教你会说话，是教你管住嘴。翻一翻，辨直话要软，嘴要严，心要明。
```
