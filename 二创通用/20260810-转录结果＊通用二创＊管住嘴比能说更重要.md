## 版本 A：核心摘要

```markdown
## 管住嘴，比能说更值钱

说话是本能，闭嘴才是本事。这辈子最隐蔽的亏，往往不是做错了事，而是说错了话——一句"我随便说说"，可能就成了别人手里的把柄；一句好心建议，可能就成了越界的冒犯；一句脱口而出的评价，可能就扎进了别人最疼的地方。真正的聪明人，不是什么都敢说，是什么都能咽回去。记住一句话：开口之前，先停三秒。
```

## 版本 B：结构化文章

```markdown
## 会说话的人很多，能闭嘴的人很少

人到中年，越来越信一句话：管住嘴，比能说更值钱。

你身边一定有这样的人——脑子快、嘴更快，什么场合都敢接话，什么人都敢评两句。年轻时觉得这叫能说会道，是本事；上了年纪才发现，那些年吃过的亏，十回有八回是嘴惹的祸。

做错了事，还能道歉、还能补救；说错了话，有时候连解释的机会都没有。你随口一句抱怨，第二天全公司都听见了；你好心一句指点，人家觉得你多管闲事；你站着说话不腰疼地评价别人的选择，没想过人家的难处根本不是你看到的那个样子。嘴一张，祸就跟着进来了——你以为你在聊天，其实你在递把柄。

这些年，我自己踩过的坑、见过的坎，掰着手指头数不过来。今天把它整理成六句话，不是大道理，是一个坑一个坑踩出来的实情。

**第一句：言多必失，先放正自己的位置。** 慎言不是胆小，是清醒。水太深、风太大，没有实力就少说话。你在公司饭局上喝的每一杯酒、说的每一句牢骚，都可能在第二天成为别人嘴里的话柄。你以为的"我随便说说"，最后便成了你职业路上的一道坎。

**第二句：别随便指点别人的人生。** 你越热心建议，人家越不领情；你替他做决定，他记你一辈子。你以为你在帮他，其实你在告诉他"我比你懂"。人家的人生，人家自己做主。你给建议点到为止，人家听不听是他的事。不懂就少说，认知不同别争辩——人各有各的渡口，不打扰就是最好的尊重。

**第三句：别随便批判别人。** 没经过别人的苦，就别劝别人善。每个人能扛的重量不一样，你站在岸上看水里的人扑腾，嫌他不游快，等你下去才知道水有多深。路边的人只看到烟，看不到心里的火。别用你的想象去评价别人的选择——你没走过他的路，别说他走的方向不对。

**第四句：学会藏好自己的底牌。** 一个人真正厉害的地方，不是什么都敢说，是什么都能藏。赚了多少钱、认识什么人、去了什么地方，恨不得昭告天下，结果找你借钱的、酸你的、背后嚼舌根的都来了。你亮出来的每一分，都是在给别人递把——嫉妒你的人记恨，不如你的人眼酸，比你强的人懒得理你。藏住底牌不是不真诚，是给自己留余地。

**第五句：远离消耗你的人。** 只要你察觉一个人心性不正，一个字都别跟他多说。有些人你救不了，也不必救。他一见面就倒苦水、一开口就怨天怨地，你出主意他不听，你劝他两句他还反咬你十句。这种人不是来找答案的，是来拉低你的。跳进去你未必爬得出来，趁早远离不是冷漠，是自保。

**第六句：看破不说破，是顶级的修养。** 你心里有数就行，没必要说穿。看清了、看懂了，笑着带过就好。曾经看不惯的人和事，时过境迁再回头，也不过淡然一笑。真正的成熟不是看破，而是看淡。心里有杆秤，谁真谁假、谁好谁坏，自己清楚就够了——没必要撕破脸，没必要争个输赢。

最后这九条不争，跟父母不争口舌、跟伴侣不争对错、跟贵人不争名利、跟小人不争道理、跟朋友不争面子、跟亲戚不争穷富、跟老人不争输赢、跟领导不争高低、跟自己不争得失。你要是能记在心里，后半辈子至少少得罪一半的人。

说话是本能，闭嘴是修行。往后余生，开口之前，先停三秒——有些话，咽回去比说出来更值。
```
